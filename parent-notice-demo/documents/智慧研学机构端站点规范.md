## 一、产品定位

机构端是"中小学素质教育综合管理平台"面向**机构**身份的 Web 端管理后台。服务于研学机构、培训机构完成研学课程/线路/活动的全生命周期管理，涵盖托管活动、社会实践、集体研学、比选中心、订单/财务结算、数据分析等业务，是机构对外提供研学服务的统一工作台。

```

```

### 5.3 状态机驱动列表（典型）

研学课程列表采用"芯片式状态筛选"代替传统下拉：
- 状态 1：上游状态（全部 / 已上架 / 已下架）
- 状态 2：报备审核状态（全部 / 未报备 / 待审核 / 已通过 / 已驳回）

这种设计在 SaaS 类系统中较为常见，优点是高频状态切换更直观。

## 六、交互与导航规范

- **顶部 Tab 切换**：研学 / 课后服务两大业务线，切换时 Sider 整体替换。
- **菜单多级**：菜单支持两级（一级 + 二级），展开/收起使用 chevron 图标。
- **Sider 折叠**：底部"《"按钮可折叠 Sider 至图标模式。
- **面包屑**：使用 `/ 一级 / 二级` 形式，每级可点击。
- **右侧浮动工具栏**：固定显示在内容区右侧，悬浮机构小程序码等快捷入口。
- **筛选区**：支持芯片式状态筛选（适合多状态快速过滤）；重置 / 查询按钮位于筛选区右侧。
- **状态徽标**：操作列中状态字段使用不同色 Tag 标识。
- **任务广场徽标**：菜单项支持红点数字徽标（待办消息提示）。
- **意见反馈**：作为常驻底部菜单入口，跨业务线统一可见。
