## 一、产品定位

**智慧研学运营后台**（劳动教育管理平台PLUS）— 面向运营管理者的 PC 端 SaaS 管理系统，覆盖研学业务的课程、订单、财务、内容、营销、签约、系统、运维等全链路业务管理。

- **终端类型**：PC Web（适配 ≥1280px 宽屏）
- **技术栈**：Ant Design v5 组件库 + 经典布局（Header + Sider + Content）
- **目标用户**：平台运营人员、商务人员、运维人员
- **设计语言**：扁平化、清晰高效、信息密度适中、蓝色主调

## 四、UI 设计规范

### 4.1 颜色体系

#### 品牌主色
| 角色 | 颜色值 | 用途 |
|---|---|---|
| **品牌主蓝** | `#2E4DD4` (rgb 46,77,212) | 顶部 Header、侧边栏、主按钮、链接 |
| **品牌亮蓝** | `#5C92FF` (rgb 92,146,255) | 选中态、强调色 |
| **品牌深蓝** | `#3A59E0` (rgb 58,89,224) | Hover 态、深色背景 |
| **信息背景蓝** | `#E8F4FF` (rgb 232,244,255) | 提示块、信息卡片底色 |

#### 中性色
| 角色 | 颜色值 | 用途 |
|---|---|---|
| **页面背景** | `#F5F6FA` (rgb 245,246,250) | 内容区底色 |
| **次级背景** | `#F2F3F5` (rgb 242,243,245) | 次按钮、表格表头、分割区域 |
| **分割线/边框** | `#F0F2F5` (rgb 240,242,245) | 卡片边框、分割线 |
| **白底** | `#FFFFFF` | 卡片、表格、弹窗 |

#### 文字色
| 角色 | 颜色值 | 用途 |
|---|---|---|
| **主要文字** | `rgba(0,0,0,0.85)` | 标题、正文 |
| **次要文字** | `rgba(0,0,0,0.45)` | 辅助说明、副标题 |
| **禁用文字** | `rgba(0,0,0,0.25)` | 禁用态、占位符 |

### 4.2 字体规范

- **字体栈**（系统字体优先）：
  ```
  -apple-system, system-ui, "Segoe UI", Roboto, "Helvetica Neue",
  Arial, "Noto Sans", sans-serif,
  "Apple Color Emoji", "Segoe UI Emoji", "Segoe UI Symbol", "Noto Color Emoji"
  ```
- **字号**（Ant Design 默认）：
  | 用途 | 字号 | 行高 |
  |---|---|---|
  | 页面大标题 | 20px | 28px |
  | 模块标题 | 16px | 24px |
  | 正文/表格 | 14px | 22px |
  | 辅助说明 | 12px | 20px |

### 4.3 间距规范

- **内容区内边距**：16px（卡片、表格等模块与边缘距离）
- **模块间距**：16px（卡片之间、表单行之间）
- **表单行高**：32px / 40px
- **按钮高度**：32px（默认）/ 24px（小）
- **输入框高度**：32px
- **表格行高**：约 48px
- **表格表头高**：39px
- **圆角**：6px（按钮/卡片）/ 2px（输入框）

### 4.4 核心组件规范

#### 按钮
- **主按钮**：背景 `#2E4DD4`、白字、圆角 6px、高 32px、字号 14px
- **次按钮**：背景 `#F2F3F5`、深色文字 `#1D2129`、圆角 6px、高 32px
- **文字按钮**：仅文字、蓝色、可带链接图标

#### 表单输入
- 输入框高 32px、圆角 2px、边框 `rgba(0,0,0,0.85)` 默认
- 下拉选择（Select）支持搜索、清空
- 表单项采用栅格布局，label 顶部对齐

#### 表格（Table）
- 表头：背景 `#F2F3F5`、字号 14px、padding 8px、高 39px
- 表格行：白底、悬停浅蓝高亮
- 列操作：通常是文字按钮（详情、移除）+ 状态开关
- 分页：底部居右，支持"共 N 条数据 / 页码 / N 条/页 / 跳至 X 页"

#### 卡片 / 数据指标卡
- 数据指标：标题 + 大字号数值 + 辅助说明 + 同比环比
- 走势/柱状图：ECharts 实现，支持 Tab 切换时间维度

#### 弹窗 / 表单
- 居中弹窗，宽度自适应
- 标题左对齐、内容居中
- 底部按钮右对齐（取消 / 确定）

#### 状态元素
- 开关（Switch）：蓝/灰两色，蓝色为启用
- 标签（Tag）：用于状态、分类
- 徽标（Badge）：数字红点提醒

#### 面包屑
- 位于内容区顶部
- 格式：`首页 / 一级菜单 / 二级菜单 / 当前页`
- 分隔符：斜杠（`/`）
- 颜色：文字色 + 蓝色当前页

## 六、交互与导航规范

### 6.1 导航模型
- **顶部 8 个 Tab**：横向模块切换，决定左侧 Sider 显示的菜单树
- **左侧 Sider**：可展开/折叠（点击底部的 `«` 按钮），支持二级菜单折叠
- **面包屑**：始终显示在内容区顶部，便于用户定位
- **二级 Tab**：部分页面（如课程中心）在内容区顶部有 Tab 切换子模块

### 6.2 通用交互
- **查询流程**：填写筛选条件 → 点击"查询"（蓝色主按钮）→ 表格刷新
- **重置**：清空筛选条件
- **新增**：右上角蓝色"添加"按钮，通常打开弹窗
- **操作列**：通常是文字链接（详情、编辑、移除）+ 状态开关
- **分页**：表格底部右下角，支持页码/每页大小/跳页
- **导出记录**：顶部右侧按钮，跳转到全局导出记录
- **全屏**：顶部右侧按钮，进入全屏模式
- **折叠 Sider**：底部 `«` 按钮，折叠为图标条

### 6.3 反馈机制
- 列表操作（添加/编辑/删除）通过 AntD `message` 弹层提示成功/失败
- 表单校验失败时字段下方显示红色错误文字
- Loading：表格/按钮操作时显示 loading 态
