# 张家口告家长通知书功能迭代 — 开发清单

|---|---|---|---|

## 阶段一：模板与数据模型重构（基础能力）

### P1-1 产品/设计

| 编号 | 任务 | 类型 | 说明 | 优先级 | 状态 |
|---|---|---|---|---|---|
| P1-1 | 数据模型设计文档 | 产品 | 定义告家长通知书独立数据结构：通知书记录表、模板表、模板授权关系表、字段映射关系表；明确与活动表的挂载关系（一对多/一对一） | P0 | 待启动 |
| P1-2 | 标准模板字段清单 | 产品 | 定义模板变量字段：活动名称、出行时间、地点、费用、保险信息、安全须知、注意事项、学校/年级、联系方式等；区分必填字段与选填字段 | P0 | 待启动 |
| P1-3 | 接口设计文档 | 产品/后端 | 设计独立模块的全部 API：模板 CRUD、模板授权 CRUD、通知书生成/查询/编辑、活动挂载/解绑等接口规范 | P0 | 待启动 |
| P1-4 | 触发方式解耦方案 | 产品 | 明确从"多行文本框手工编辑 → 有内容即挂载"到"功能开关 + 模板引用 + 在线编辑生成 → 挂载"的改造路径；定义新旧数据并存与迁移策略 | P0 | 待启动 |

### P1-2 后端开发

| 编号 | 任务 | 类型 | 说明 | 优先级 | 状态 |
|---|---|---|---|---|---|
| B1-1 | 告家长通知书独立数据模型建表 | 后端 | 按数据模型设计文档创建数据库表结构，含索引设计；与现有活动表建立关联字段，保持兼容 | P0 | 待启动 |
| B1-2 | 运营后台模板配置接口 | 后端 | 模板创建、编辑、启用/停用、删除（软删）接口；模板内容支持富文本 + 变量占位符定义；模板不内置、不预置 | P0 | 待启动 |
| B1-3 | 模板授权机制接口 | 后端 | 运营后台将模板授权给指定商户（支持按商户/区域批量授权）；商户端查询可用模板列表接口（仅返回已授权模板） | P0 | 待启动 |
| B1-4 | 活动基础信息自动预填链路 | 后端 | 根据活动 ID 自动获取出行时间、地点、费用、学校/年级等信息，映射到模板变量字段，返回预填数据供前端渲染 | P1 | 待启动 |
| B1-5 | 告家长通知书数据与活动挂载关系重构 | 后端 | 将当前"多行文本字段存储在活动表中"改为"独立通知书记录 + 活动关联外键"；提供挂载/解绑接口；保留历史纯文本数据兼容读取 | P0 | 待启动 |

### P1-3 前端开发

| 编号 | 任务 | 类型 | 说明 | 优先级 | 状态 |
|---|---|---|---|---|---|
| F1-1 | 运营后台模板配置页面 | 前端 | 模板列表（含启用/停用状态）、模板新建/编辑表单（富文本编辑器 + 变量占位符插入）、模板预览 | P0 | 待启动 |
| F1-2 | 运营后台模板授权页面 | 前端 | 模板授权管理界面：选择模板 → 选择商户/区域 → 批量授权/回收；已授权列表查看与筛选 | P0 | 待启动 |

### P1-4 验收要点

- [ ] 数据模型独立于活动表，通过外键关联
- [ ] 运营后台可创建/编辑/启停模板，模板不内置
- [ ] 运营后台可将模板授权给商户，商户仅能使用已授权模板
- [ ] 历史纯文本数据可正常读取，不受模型重构影响

## 阶段二：在线编辑与文件生成能力

### P2-1 前端开发

| 编号 | 任务 | 类型 | 说明 | 优先级 | 状态 |
|---|---|---|---|---|---|
| F2-1 | 商户端在线填写页面 | 前端 | 根据已授权模板的变量字段动态渲染表单；活动基础信息自动预填；支持手动修改补充 | P0 | 待启动 |
| F2-2 | 告家长书内容预览 | 前端 | 填写变量后实时/点击预览，渲染完整告家长书内容（模板 + 变量替换后效果） | P0 | 待启动 |
| F2-3 | "生成文件"按钮与交互 | 前端 | 提交填写数据 → 调用后端生成接口 → 展示生成结果/加载态；生成成功后展示文件预览与后续操作入口 | P0 | 待启动 |

### P2-2 后端开发

| 编号 | 任务 | 类型 | 说明 | 优先级 | 状态 |
|---|---|---|---|---|---|
| B2-1 | 模板渲染引擎 | 后端 | 接收变量数据 + 模板内容 → 变量占位符替换 → 生成完整告家长书 HTML/内容；支持富文本与变量混排 | P0 | 待启动 |
| B2-2 | PDF 生成服务 | 后端 | 将渲染后的内容转为 PDF 文件；排版适配 A4 打印格式；返回文件 URL | P0 | 待启动 |
| B2-3 | 关键告知事项必填校验 | 后端 | 提交时校验保险信息、安全预案等关键字段非空；校验规则可配置（随模板字段定义）；校验失败返回明确提示 | P0 | 待启动 |
| B2-4 | 电子签名触发逻辑保留 | 后端 | 活动挂载告家长通知书内容后，家长报名时仍弹出电子签名签字；兼容纯文本来源（历史数据）与模板生成来源（新数据）两种情况 | P0 | 待启动 |

### P2-3 验收要点

- [ ] 商户端可选择已授权模板，在线填写变量信息
- [ ] 活动基础信息自动预填，可手动修改
- [ ] 点击生成后产出完整告家长书内容与 PDF
- [ ] 关键告知事项缺失时阻断生成并提示
- [ ] 家长报名时电子签名正常弹出（新旧数据均兼容）

## 阶段三：导出与归档闭环

### P3-1 后端开发

| 编号 | 任务 | 类型 | 说明 | 优先级 | 状态 |
|---|---|---|---|---|---|
| B3-1 | Word 导出能力 | 后端 | 在 PDF 生成基础上，增加 Word（.docx）导出；保留模板排版与格式，便于机构二次编辑 | P1 | 待启动 |
| B3-2 | 自动归档至报备材料 | 后端 | 生成 PDF 文件后，自动将文件归档至对应活动的"报备材料"模块；建立归档记录（生成时间、操作人、文件类型） | P0 | 待启动 |
| B3-3 | 报备材料检索与预览接口 | 后端 | 报备材料列表支持按活动 ID 检索；支持文件在线预览（PDF）；支持重新生成（覆盖/追加） | P1 | 待启动 |

### P3-2 前端开发

| 编号 | 任务 | 类型 | 说明 | 优先级 | 状态 |
|---|---|---|---|---|---|
| F3-1 | 报备材料列表与预览页 | 前端 | 活动详情中展示报备材料列表；支持点击预览 PDF；支持重新生成操作（二次确认） | P1 | 待启动 |
| F3-2 | 导出操作入口 | 前端 | 在告家长书生成结果页/报备材料列表中提供 PDF / Word 双格式导出按钮 | P1 | 待启动 |

### P3-3 验收要点

- [ ] 支持 PDF 和 Word 双格式导出
- [ ] PDF 排版适配 A4 打印
- [ ] 生成文件自动归档至活动报备材料
- [ ] 报备材料可检索、预览、重新生成

## 阶段四：独立功能单元化与生态完善

### P4-1 产品/设计

| 编号 | 任务 | 类型 | 说明 | 优先级 | 状态 |
|---|---|---|---|---|---|
| P4-1 | 独立功能入口设计 | 产品 | 在机构端/学校端设计告家长通知书独立入口（脱离活动创建流程），支持独立查看/管理已生成的通知书 | P1 | 待启动 |
| P4-2 | 权限与可见范围配置方案 | 产品 | 设计机构/学校/平台三层权限体系：运营后台管理模板与授权，商户管理本机构通知书，学校查看本校活动相关通知书 | P2 | 待启动 |
| P4-3 | 使用文档与操作指引 | 产品 | 输出运营后台操作指引（模板配置/授权）与商户端操作指引（在线填写/生成/导出） | P2 | 待启动 |

### P4-2 后端开发

| 编号 | 任务 | 类型 | 说明 | 优先级 | 状态 |
|---|---|---|---|---|---|
| B4-1 | 活动创建挂载入口改造 | 后端 | 活动创建流程中引入功能开关：开启 → 走"选已授权模板 → 在线编辑生成"流程；关闭 → 不挂载通知书；替代当前"多行文本框手工录入"方式 | P0 | 待启动 |
| B4-2 | 历史纯文本数据兼容读取 | 后端 | 活动创建改造后，对既有活动的历史纯文本数据保持兼容读取与展示；新旧数据类型标记区分 | P0 | 待启动 |
| B4-3 | 模板版本管理 | 后端 | 运营后台模板更新时生成新版本号；已生成的通知书保留生成时的模板版本快照，不受后续模板修改影响 | P1 | 待启动 |
| B4-4 | 模板授权管理完善 | 后端 | 运营后台按商户/区域灵活授权与回收；授权变更记录日志；模板停用后已生成文件不受影响、新生成时阻断并提示 | P1 | 待启动 |

### P4-3 前端开发

| 编号 | 任务 | 类型 | 说明 | 优先级 | 状态 |
|---|---|---|---|---|---|
| F4-1 | 活动创建告家长书开关交互 | 前端 | 活动创建表单中增加"告家长书"功能开关；开启后展示模板选择（仅已授权）→ 在线编辑填写流程；关闭则隐藏相关区域 | P0 | 待启动 |
| F4-2 | 独立功能入口页面 | 前端 | 机构端/学校端新增告家长通知书独立管理页面：通知书列表、状态筛选、查看详情、重新生成 | P1 | 待启动 |
| F4-3 | 权限分层控制前端适配 | 前端 | 按角色（运营/商户/学校）控制功能入口与操作权限的可见性 | P2 | 待启动 |

### P4-4 联调与回归

| 编号 | 任务 | 类型 | 说明 | 优先级 | 状态 |
|---|---|---|---|---|---|
| T4-1 | 与三方比选流程联动回归 | 测试 | 验证告家长书功能在三方比选流程中的正常表现（创建活动 → 开关 → 模板 → 生成 → 挂载 → 报名签名） | P0 | 待启动 |
| T4-2 | 与集体研学活动详情联动回归 | 测试 | 验证活动详情页中告家长通知书的展示、报备材料归档、电子签名等端到端流程 | P0 | 待启动 |
| T4-3 | 历史数据兼容回归 | 测试 | 验证既有活动（纯文本告家长书）在新模型下的读取、展示、签名流程正常 | P0 | 待启动 |

### P4-5 验收要点

- [ ] 活动创建中有明确的告家长书开关，开启后走模板化流程
- [ ] 历史纯文本数据正常兼容读取
- [ ] 机构端/学校端有独立入口管理通知书
- [ ] 模板版本管理：更新模板不影响已生成通知书
- [ ] 模板授权可灵活授予/回收，停用后已生成文件不受影响
- [ ] 三方比选、集体研学等既有流程回归通过
- [ ] 权限分层控制生效
